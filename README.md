Lliurament 3 - Programa de temperatura

Aquest programa en C mostra una temperatura en graus Celsius, en calcula la conversió a graus Fahrenheit i indica si la temperatura és alta (20 graus o més) o baixa (menys de 20 graus).

Compilació:
Des d'un terminal situat a la carpeta del projecte, executeu:
gcc -Wall -Wextra temperatura.c -o temperatura

Execució:
./temperatura

Sortida esperada
Temperatura: 25 graus
Fahrenheit: 77.0 graus
Temperatura alta
